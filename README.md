# 📊 HR Attrition Analysis Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive **HR Attrition Analysis Dashboard** developed using **Microsoft Power BI**.

The main objective of this project is to analyze employee attrition, understand workforce characteristics, identify turnover patterns, and provide data-driven insights that can support HR decision-making and employee retention strategies.

The dashboard is designed as a multi-page analytical report consisting of:

- Executive Overview
- Employee Analysis
- Attrition Insights

---

## 🎯 Business Objective

Employee turnover can have a significant impact on recruitment costs, productivity, workforce stability, and overall business performance.

This project aims to answer key HR questions such as:

- What is the overall employee attrition rate?
- Which departments have the highest number of attritions?
- How does overtime relate to employee attrition?
- Which business travel categories have the highest attrition counts?
- How does job satisfaction vary across different job roles?
- What are the characteristics of employees who leave the organization?
- Are there specific employee groups that require more attention from HR?

## 🔍 Key Insights

The dashboard highlights several important patterns within the HR data:

- The overall **attrition rate is 16.12%**, with **237 employees** recorded as attrition cases.
- **Research & Development** has the highest attrition count among the departments shown.
- Employees classified as **Travel_Rarely** represent the largest number of attrition cases.
- Attrition cases are distributed across different levels of **Job Satisfaction**, highlighting the importance of considering multiple employee factors rather than relying on a single metric.
- Employees with **OverTime = Yes** account for a larger number of attrition cases than employees with OverTime = No.
- Employees with different numbers of previously worked companies show noticeable differences in attrition patterns.
- Job satisfaction varies across job roles, providing useful information for understanding employee experience.

> Note: These findings describe patterns in the dataset and should not automatically be interpreted as causal relationships.

## 📈 Data Analysis Process

The project followed a structured data analysis workflow:

### 1. Data Preparation
- Imported the HR dataset into Power BI.
- Reviewed the structure and data types.
- Identified relevant fields for HR and attrition analysis.

### 2. Data Cleaning & Transformation
- Cleaned and transformed the dataset using **Power Query**.
- Prepared fields for analysis and visualization.
- Ensured consistent data types and categorical values.

### 3. Data Modeling
- Organized the data model to support interactive analysis.
- Created the required relationships and analytical fields.

### 4. DAX & KPI Development
Created calculated measures to support important HR metrics such as:

- Total Employees
- Attrition Count
- Attrition Rate
- Average Age
- Average Monthly Income
- Average Working Years
- Average Job Satisfaction
- Average Work-Life Balance
- Average Environment Satisfaction

### 5. Dashboard Development
Designed an interactive multi-page Power BI dashboard with:

- KPI Cards
- Bar Charts
- Donut Charts
- Line Charts
- Slicers
- Navigation Buttons
- Interactive Filters
